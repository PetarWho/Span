# Span for Android

The Android app for [Span](../README.md), built with Flutter. It speaks the same
encrypted protocol as `span.py`, so phones and computers work together.

```
flutter build apk --release                 # build/app/outputs/flutter-apk/app-release.apk
flutter test test/interop_test.dart         # Dart protocol vs span.py (needs Python + cryptography)
```

- `lib/core/` is the protocol: encrypted channel, discovery, receiver, browse sessions, relay.
  It mirrors `span.py`, so keep the two in sync.
- `lib/ui/` holds the screens, `lib/app_state.dart` ties them together.
- Launcher icons are generated by `../tools/make_icon.py`.
